シンデレラガールズ総選挙のシリアルコードを撮影して、コピーして、
公式入力ページを開くためのAndroid用補助アプリです。
スマホのキーをぽちぽちするのが面倒くさい！と思い作りました。
このアプリはチャンジャが作りました。


## このアプリについて
- 非公式のファンメイドアプリです
- 公式・関係各社とは関係ありません
- シリアルコードの撮影と文字認識を端末内で行います
- ログイン情報の取得は行いませんので、ご自身のバンダイナムコIDでログインしてください
- 自動入力・自動送信は行いません（すべて自動で行うと公式サイトへの負荷がかかるため）
- 読み取ったシリアルコードが合っているかを使用前に必ずご自身で確認してください

## 対応環境
Android

2026年9月18日 23:59まで

※総選挙期間にあわせて公開します。
※配布終了後の更新・動作保証は行いません。


## インストールについて
グーグルプレイストアではなくGitHubで配布するアプリのため、
スマホの設定でこのアプリの「不明なアプリのインストール」を許可する必要があります。
インストール後は、その許可を元に戻してください。

## 正規配布元
このGitHubリポジトリのReleasesページのみです。
第三者が再配布したAPKは使用しないでください。
このアプリはAPK形式で配布します

## プライバシー
- 撮影画像と読み取り結果は端末内に保存されます
- シリアルコードや写真を外部サーバーへ送信しません
- 広告・アクセス解析・ユーザー登録はありません
- アプリ内の「すべての履歴を削除」またはアンインストールで保存データを削除できます
